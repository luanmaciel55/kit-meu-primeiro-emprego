# Kit Meu Primeiro Emprego

Projeto gratuito para ajudar pessoas na busca por uma oportunidade profissional.

Recursos: currículo para primeiro emprego ou profissionais com experiência, currículo com ou sem foto, geração e compartilhamento de PDF, preparação para entrevistas, postura, vestimenta, mensagens para envio de currículo, checklist, controle de candidaturas e ferramentas auxiliares.
